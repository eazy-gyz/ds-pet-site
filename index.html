放心用

不申请「网络访问」权限

这不是一句宣传语——DS桌宠的安装包里根本没有 INTERNET 权限。 也就是说，从技术上它就没有能力把任何数据传出去。 你可以自己在「设置 → 应用 → DS桌宠 → 权限」里核实。

  • 不收集任何个人信息，不采集设备标识（IMEI / OAID / Android ID）
  • 不集成任何第三方 SDK：没有统计、没有广告、没有推送
  • 不申请位置、通讯录、短信、相机、麦克风、存储权限
  • 动画、语音、签文、纸条文案全是安装包里的本地文件，一个字节都不下载
  • 1.3 新增的今日签 / 图鉴徽章 / 分享海报，也全部在本机完成，不上传任何图片和文字

常见问题

你可能想问

她真的不联网吗？

真的。安装包里没有 INTERNET 权限，从技术上就不具备联网能力。动画、语音、签文、纸条文案都是打包在本地的文件。你可以到系统「应用信息 → 权限」里亲自核实——那一栏里不会有「网络」。

升到 1.3 会丢数据吗？

不会。用的是同一把签名，直接覆盖安装就行：陪伴天数、互动次数、打卡记录、已解锁的徽章、你给她起的名字和性格、各种设置，全都保留。实测覆盖安装十几次，数据一条没掉。

「今日签」需要联网吗？准不准？

不需要联网。60 条签文和宜 / 忌都在安装包里，按「一年中的第几天」取值，同一天翻回来永远是同一张，抽签还会避开最近抽到过的。它就是个讨彩头的小设计，不做任何预测。

分享会不会往我相册里塞东西？

不会。点「分享」只写一份临时文件递出去，只有你自己点「保存到相册」才会写入相册（静态图进 Pictures/DS桌宠，动图进 Movies/DS桌宠）。

会不会很耗电？

不会。灭屏后她会立刻停下所有动作和声音，实测 CPU 从约 120% 降到 0.0%。亮屏时才活动，动作 / 说话频率都可以调低，1.3 还多了「省电模式」。

为什么锁屏后她就不出声了？

这是故意的。锁屏时看不见她，出声只会打扰你，所以屏幕一灭就停语音、停动作。亮屏自动恢复。

桌宠被手机管家清掉了怎么办？

去「设置 → 电池 → 后台高耗电」放行一下，再到「应用管理 → 权限 → 自启动」打开，最后在最近任务里把她锁定。App 里的设置页也写了这几步。

iPhone 上为什么不能像安卓那样浮在别的 App 上？

iOS 不给第三方 App 这个权限，也不允许读取其他应用的通知——这是系统限制，不是我们偷懒。iOS 版目前是网页版（可添加到主屏幕全屏使用）。

要花钱吗？有广告吗？

不要钱。没有广告、没有内购、没有会员，也不收集你的任何信息。这是一个免费分享的小作品。
